# Solvro Cocktails

App for browsing cocktails made for the KN Solvro frontend recruitment task. It uses the Solvro Cocktails API (https://cocktails.solvro.pl).

Demo: https://solvro-cocktails-app.vercel.app

## What it does

- list of cocktails with pagination
- search cocktails by name
- cocktail page with ingredients, glass and instructions
- adding cocktails to favourites (saved in localStorage)

## Stack

- Next.js
- TypeScript
- TanStack Query
- Jotai
- shadcn/ui and Tailwind

## How to run

```
npm install
npm run dev
```

Then open http://localhost:3000
